# Eggx MVP Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build Eggx, a responsive static directory of verified free AI coding offers with human pages and a machine-readable REST, RSS, and llms.txt interface.

**Architecture:** Astro statically renders content from `src/content/offers.ts` and `src/content/daily.ts`. Shared query and validation helpers feed the UI and generated API routes, keeping the site and agent contract consistent without a database. A compact mobile-first CSS system presents the three offer categories, evidence state, and expiry urgency.

**Tech Stack:** Astro, TypeScript, Vitest, Astro RSS, static deployment on GitHub Pages.
